# Voice Notes AI - Android Project (Capacitor)

Dự án này đóng gói web app ghi chú giọng nói + nhận diện ảnh thành ứng dụng Android.

## Cách build file APK trên GitHub (khuyến nghị)

1. Vào tab **Actions** của repo
2. Chọn workflow **Build Android APK**
3. Nhấn **Run workflow** → chọn branch `main` → **Run workflow**
4. Đợi build xong (khoảng 3-5 phút)
5. Vào run mới nhất → kéo xuống phần **Artifacts** → tải file `VoiceNotesAI-debug.apk`

## Cách build local bằng Android Studio

1. Cài Android Studio
2. Mở thư mục `android`
3. Build → Build Bundle(s)/APK(s) → Build APK(s)

APK sẽ nằm tại `android/app/build/outputs/apk/debug/app-debug.apk`
